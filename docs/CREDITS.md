# Créditos de imágenes

Todas las fotografías proceden de [Unsplash](https://unsplash.com) y se usan bajo la
[Licencia Unsplash](https://unsplash.com/license) (uso gratuito, atribución no obligatoria pero recomendable).
Se sirven desde `images.unsplash.com` mediante `next/image`.

La API de búsqueda de Unsplash requiere una clave, así que los nombres de los autores no se pudieron obtener de forma automatizada.
Cada foto se identifica por su ID de CDN, que permite localizar la página original y a su autor.
